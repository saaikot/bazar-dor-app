# 🛒 Bazar Dor

> A price tracking web application for Bangladeshi daily essentials.

## 📖 About

**Bazar Dor** is a full-stack web application that tracks the daily prices of essential goods in Bangladesh. Users can view current prices, price trends, and market-wise comparisons for rice, lentils, oil, vegetables, fish, meat, eggs, milk, and spices — all in one place.

- **Live Demo:** [https://bazar-dor-app.vercel.app](https://bazar-dor-app.vercel.app)

## ✨ Key Features

1. **Home Page** — Displays all products with today's prices, plus top 6 risers and fallers.
2. **Category Filter** — Browse products by 8 categories (rice, lentils, oil, vegetables, fish, meat, eggs & milk, spices).
3. **Sorting** — Sort by price low-to-high or high-to-low with Bengali numeral support.
4. **Product Details (Protected Route)** — Shows min, max, and average prices along with a market-wise price breakdown across 12 markets.
5. **Authentication (BetterAuth)** — Email/password sign up, sign in, and profile update functionality.
